# 广州版三上 U1–U4 周末刷词

广州版三年级上册 Unit 1–Unit 4 周末刷词网页（共 83 词）：先学后测（认识 → 跟读 → 英中/中英遮盖回忆），学完小批再测；周末后可「每日练」默写巩固。音标醒目展示。

## 在线访问（GitHub Pages）

https://wendyleung160712-cloud.github.io/knowledge1/

## 本地运行

```bash
npm install
# 本地开发可把 vite.config.ts 里的 base 临时改成 '/'
npm run dev
```

浏览器打开 http://localhost:8083/

## 构建

```bash
npm run build
```

产物在 `dist/`。仓库通过 `gh-pages` 分支部署到 GitHub Pages（`base` 为 `/knowledge1/`）。
